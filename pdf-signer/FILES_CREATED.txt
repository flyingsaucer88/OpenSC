Quick Commands
==============
Desktop Build:
  cd pdf-signer/desktop && mvn clean package

Desktop Sign:
  java -jar target/pkcs11-pdf-signer-1.0.0-jar-with-dependencies.jar \
    ../opensc-pkcs11.cfg 1234 input.pdf signed.pdf

Android Usage:
  AndroidPDFSigner signer = new AndroidPDFSigner(context);
  signer.initialize(usbDevice, "1234");
  signer.signPDF(input, output, "Name", "Location", "Reason");
